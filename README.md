# KRMP Support Bot

Telegram-бот для проекта KRMP: тех. поддержка, жалобы на игроков, заявки на администратора.

## Возможности
- **Тех. поддержка** — анкета (ник, описание проблемы, скриншот), диалог с админом внутри бота.
- **Жалобы** — ник заявителя и нарушителя, дата, суть, доказательства (ссылка или фото).
- **Заявка в админы** — анкета кандидата; админы нажимают «Принять» / «Отклонить», кандидат получает уведомление.
- **Мои обращения** — список последних обращений и их статусы.
- Обращения приходят в чат персонала с кнопками: Взять / Ответить / Закрыть.
- Лимит открытых обращений на пользователя (защита от спама), хранение в SQLite.

## Установка
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Создайте группу для персонала, добавьте туда бота.
   - В BotFather: `/mybots` → ваш бот → Bot Settings → Group Privacy → **Turn off**
     (иначе бот не увидит ответы админов в группе).
3. В группе и в личке с ботом отправьте `/id` — получите `STAFF_CHAT_ID` и свой Telegram ID.
4. Скопируйте `.env.example` в `.env` и заполните.
5. Запуск:
```bash
pip install -r requirements.txt
python bot.py
```

## Как работает ответ админа
Нажмите «✍️ Ответить» под обращением → отправьте текст → бот перешлёт его пользователю.
Пользователь может ответить кнопкой «💬 Ответить», сообщение вернётся в чат персонала.

## Настройка
Тексты вопросов анкет — словарь `FORMS` в начале `bot.py`. Лимиты открытых обращений — `OPEN_LIMIT`.
